API Gravity and Specific Gravity

Video lesson: API Gravity and Specific Gravity

API Gravity Calculator

This calculator converts oil specific gravity (S.G. at 60°F/60°F) to API gravity, or the other way round. It also classifies the crude.

°API = 141.5 / SG − 131.5
SG = 141.5 / (°API + 131.5)

Inputs and units

  • Specific gravity SG, dimensionless relative to water (greater than 0)
  • Or API gravity in °API (API + 131.5 must be greater than 0)

Crude classification in the calculator

°APIClass
Above 31.1Light Crude
22.3 up to 31.1Medium Crude
10.0 up to 22.3Heavy Crude
Below 10.0Extra Heavy / Denser than Water

Worked example

SG = 0.85, and then an oil of 35 °API.

°API = 141.5 / 0.85 − 131.5 = 34.97
SG = 141.5 / (35 + 131.5) = 0.8498
Water has an SG of 1.000, which is 10.0 °API. Higher °API means a lighter oil with a lower SG.

Specific Gravity Calculator (from API)

This calculator gives the specific gravity from the API gravity, with density equivalents at 60°F.

SG = 141.5 / (API + 131.5)
ρ (kg/m³) ≈ SG × 999.016
ρ (lb/ft³) ≈ SG × 62.366

Inputs and units

  • API gravity in °API (API + 131.5 must be greater than 0)
  • Results: SG, crude grade, density in kg/m³ and lb/ft³

Worked example

An oil of 35 °API.

SG = 141.5 / (35 + 131.5) = 0.8498
ρ = 0.8498 × 999.016 = 849.0 kg/m³
ρ = 0.8498 × 62.366 = 53.00 lb/ft³
Light crude oils are typically 35 to 45 °API with an SG of about 0.80 to 0.85. Heavier oils have lower °API and an SG closer to or above 1.00.

API Gravity Correction (to 60°F)

A hydrometer reads the API gravity at the sample temperature. This calculator standardizes the reading to 60°F, following ASTM D1250.

SGobs = 141.5 / (131.5 + APIobs)
VCF = e−0.000413 × ΔT × (1 + 0.8 × 0.000413 × ΔT), with ΔT = Tobs − 60
SG60 = SGobs / VCF
API60 = 141.5 / SG60 − 131.5
Density (kg/m³) = SG60 × 1000

Inputs and units

  • Observed API gravity from the hydrometer
  • Observed temperature in °F, read at the same moment
  • Results: API at 60°F, SG at 60°F and density in kg/m³

Worked example

Observed API = 43.2 at 100°F.

ΔT = 100 − 60 = 40
SG60 = 0.8236
API60 = 40.3
Record the temperature at the exact moment of the API reading. If the corrected API is very different from previous samples, check the hydrometer for wax build-up. The page gives a rule of thumb: API increases by about 0.08 for every 1°F increase.

Oil Gravity Temperature Correction

This calculator converts an observed S.G. (or API) and temperature to standard conditions at 60°F, with a simple linear correction.

correction factor = 0.00069 − 0.0003725 × SGobs
SG60 = SGobs + factor × (Tobs − 60)
API60 = 141.5 / SG60 − 131.5

Inputs and units

  • Observed S.G. or observed API
  • Observed temperature in °F (the calculator uses 60 if it is empty)

Worked example

Observed SG = 0.800 at 80°F.

factor = 0.00069 − 0.0003725 × 0.8 = 0.000392
SG60 = 0.8 + 0.000392 × 20 = 0.8078
API60 = 43.7
This page uses a linear factor, while the API Gravity Correction page uses a volume correction factor, so the two methods can give slightly different answers.

API and K-Factor Correction

This calculator corrects the observed API to 60°F using the hydrometer temperature. It then gives the K-factor (VCF) for the oil line temperature, which adjusts the volume from line conditions to standard conditions.

Step 1: ρobs = 141360.198 / (131.5 + APIobs), then ρt = ρobs × [1 − 0.00001278 (T − 60) − 0.0000000062 (T − 60)2]
α = 341.0957 / ρt2, VCF = e−αΔT (1 + 0.8 αΔT), ρ60 = ρt / VCF
API60 = 141360.198 / ρ60 − 131.5
Step 2: K = V60 / Vline, from API60 and the line temperature

Inputs and units

  • Observed API
  • Hydrometer temperature in °F
  • Oil line temperature in °F
  • Results: oil API at 60°F and K-factor (VCF), shown with 5 decimals

Worked example

Observed API = 50, hydrometer temperature = 78°F and oil line temperature = 90°F (the example values on the page).

API60 = 48.20
K-factor = 0.98391
The K-factor is below 1 when the line is warmer than 60°F, because warm oil takes more volume than the same oil at 60°F.
