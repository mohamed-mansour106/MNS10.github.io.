Unit Conversions

Video lesson: Unit Conversions

Pressure Conversion

The pressure converter changes a value in any field into all the other units at the same time. Internally it converts the entered value to psig, then to each unit.

psig = value / factor(unit)
result = psig × factor(result unit)

Factors (units per 1 psig)

UnitFactor
bar0.0689476
kPa6.89476
atm0.068046
inH2O27.7076
ftH2O2.30896
inHg2.03602
mmHg51.7149
kgf/cm²0.070307

Worked example

Convert 100 psig and 10 bar.

100 psig × 0.0689476 = 6.8948 bar
100 psig × 6.89476 = 689.476 kPa
10 bar / 0.0689476 = 145.04 psig
The converter works in psig, so it is a gauge-pressure converter. Check whether your pressure is gauge or absolute before you use it.

Temperature Conversion

The temperature converter changes between Fahrenheit, Celsius, Kelvin and Rankine. It converts the input to Celsius first.

°C = (°F − 32) × 5/9, or K − 273.15, or (°R − 491.67) × 5/9
°F = °C × 9/5 + 32
K = °C + 273.15
°R = (°C + 273.15) × 9/5

Worked example

Convert 100 °F.

°C = (100 − 32) × 5/9 = 37.78
K = 37.78 + 273.15 = 310.93
°R = (37.78 + 273.15) × 9/5 = 559.67
Results are shown with two decimals. Rankine is the scale used in gas calculations, for example T = °F + 460.

inches = value × factor(unit)

Rates Conversion

The rates converter changes liquid flow rates between imperial and metric units. It works from bbl/day.

bbl/day = value × factor(unit)
result = bbl/day / factor(result unit)

Factors (bbl/day per unit)

UnitFactor

m³/day6.2898

Worked example

Convert 500 gal/min.

bbl/day = 500 × 34.2857 = 17,142.8
m³/day = 17,142.8 / 6.2898 = 2,725.5
1 bbl/min = 1,440 bbl/day because there are 1,440 minutes in a day.

Density Conversion

The density converter includes API gravity and specific gravity (S.G.). It works from S.G., with water = 1.

S.G. = 141.5 / (API + 131.5)
API = (141.5 / S.G.) − 131.5
S.G. = value × factor(unit)

Factors (S.G. per unit)

UnitFactor
ppg (lb/gal)0.119826
lb/ft³0.016018
g/cc (kg/L)1
psi/ft (gradient)2.30896
bar/m10.209

Worked example

Convert an oil of 35 °API.

S.G. = 141.5 / (35 + 131.5) = 0.8498
ppg = 0.8498 / 0.119826 = 7.0924
psi/ft = 0.8498 / 2.30896 = 0.3681
g/cc and S.G. are the same number (factor 1).

Flow Rate Conversions

This converter covers common field units for liquid and gas flow. It converts the input to litres per second, then to each unit.

L/s = value × input factor
result = L/s × output factor

Choke Size Conversion

Choke sizes are quoted in 64ths of an inch. This converter links 64ths, decimal inches and millimetres.

IDinch = Choke Size / 64
IDmm = IDinch × 25.4

Inputs and units

  • Choke size in 1/64 inch
  • Decimal equivalent in inches (shown with 3 decimals)
  • Metric equivalent in mm (shown with 2 decimals)

Worked example

Convert a 32/64 choke.

IDinch = 32 / 64 = 0.500 in
IDmm = 0.5 × 25.4 = 12.70 mm
1 inch = 64/64 and 1 inch = 25.4 mm. You can type in any of the three fields.

Use the Choke Size Conversion Calculator to check your own numbers.
