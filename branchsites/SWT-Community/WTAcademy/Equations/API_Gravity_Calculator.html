API Gravity Equation Calculator

Convert oil Specific Gravity (\(\text{SG}\) at \(60^\circ\text{F}/60^\circ\text{F}\)) to API Gravity (°API), or enter °API to calculate Specific Gravity.

Dimensionless relative to water (> 0)
Reverse solves \(\text{SG} = \frac{141.5}{^\circ\text{API} + 131.5}\)

API Gravity (°API)

$$^\circ\text{API} = \frac{141.5}{\text{SG}} - 131.5$$

Specific Gravity (\(\text{SG}\))

$$\text{SG} = \frac{141.5}{^\circ\text{API} + 131.5}$$

Crude Classification

$$>31.1\text{ Light} \mid 22.3\text{–}31.1\text{ Medium} \mid \le 22.3\text{ Heavy}$$

Field Note: Water has a specific gravity of 1.000, which corresponds to 10.0 °API. Higher °API values indicate lighter oils with lower specific gravity, while values below 10 °API correspond to fluids denser than water (SG > 1.0).
