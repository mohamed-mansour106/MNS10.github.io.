Engineering Reference - Variable Definitions
  • Int.T: Meter increment.
  • Pf: Separator pressure (psia).
  • HW: Differential pressure (∆P).
  • Fb: Basic orifice flow factor.
  • Fg: Specific gravity factor.
  • Ftf: Flowing temperature factor.
  • Fpv: Super-compressibility factor.
  • Fr: Reynolds number factor.
  • Y2: Expansion factor.
  • Ftb: Temperature base factor (default = 1).
  • Fpb: Pressure base factor (default = 1).
  • C: Combined correction factor.
